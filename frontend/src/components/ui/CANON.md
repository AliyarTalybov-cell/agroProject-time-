# Канон интерфейса

Единые правила для всех страниц. Эталон — shadcn-vue (new-york), цвета — наша тема
(`styles/shadcn.css`). Образец страницы по канону — «Задачи» (`pages/TaskManagementPage.vue`).

## Отступы — только эта шкала

| Где | Значение | Tailwind |
|---|---|---|
| Поле контента страницы | 16px телефон, 24px от 768px | задано в `.main-content-inner`, на странице не добавлять |
| Между блоками страницы | 24px | корень страницы `flex flex-col gap-6` |
| Между связанными рядами (панель + фильтры) | 16px | `-mt-2` у второго ряда |
| Между полями формы | 16px | `FormGrid` (`gap-4`) |
| Подпись → поле → подсказка | 8px | `FormField` (`gap-2`) |
| Элементы в ряду (кнопки, фильтры) | 8px | `gap-2` |
| Внутри карточки | 16px телефон / 24px десктоп | `p-4` / `p-6` (Card) |
| Ячейки таблицы | Table shadcn, крайние `pl-4` / `pr-4` | — |

Значения вроде 5, 7, 10, 14, 18, 22px не используются.

## Размеры

- Высота полей, селектов, кнопок в панели — `h-9` (по умолчанию у компонентов). `size="sm"` (h-8) — только внутри строк, карточек и подвалов списков.
- Текст: 14px основной (`text-sm`), 12px вторичный (`text-xs text-muted-foreground`), заголовок окна — 18px (`text-lg font-semibold`), заголовок секции — `text-sm font-medium`. Капс-подписи не используем.
- Иконки: 16px (`size-4`, по умолчанию в Button), 14px в заголовках таблиц.
- Радиусы: поля и кнопки — `rounded-md`, карточки и таблицы — `rounded-xl`, бейджи и чипы — `rounded-full`.
- Аватар: 24px в таблицах и чипах, 32px в карточках, 36px в формах.

## Каркас страницы

```vue
<section class="tw-scope flex flex-col gap-6">
  <PageToolbar> вкладки/фильтры <template #actions> действия </template></PageToolbar>
  <div class="-mt-2 grid grid-cols-2 gap-2 sm:flex sm:flex-wrap"> фильтры </div>
  реестр: Table в `rounded-xl border` (десктоп) + карточки `md:hidden` (телефон)
  UiPagination
</section>
```

- Заголовок страницы уже в шапке (`app-topbar`) — на странице его не повторять.
- `tw-scope` на корне — сброс браузерных стилей у своих button/ul/p/h* (preflight отключён).
- Загрузка — Skeleton той же формы, что и контент; пусто — Empty; ошибка — Alert.

## Окна

- Только `UiModal` / `UiConfirmModal`. Тело — `FormGrid :cols="2"`, поля — `FormField` (`wide` — во всю ширину). Счётчик символов — `:count` / `:max` у `FormField`, не отдельной строкой.
- Подвал: справа «Отмена» (outline) + основное действие; «Удалить» — слева, `variant="danger-quiet"`. Красная заливка — только у кнопки подтверждения удаления.
- Ширина: 560 форма, 672 большая форма, 940 карточка с боковой колонкой, 460 подтверждение.

## Цвета и тема

- Только токены: `bg-background/card/muted`, `text-foreground/muted-foreground`, `border` (цвет темы ставится сам), `primary`, `destructive`.
- Статусы, приоритеты, культуры — `UiBadge` с тоном (neutral / info / warning / success / danger / primary); свои цвета бейджей не заводить.
- Жёстко заданные `#hex` и `rgba()` в стилях страниц не используются — тёмная тема тогда работает сама.

## Старые стили

Переведённая страница теряет свой старый CSS: `node scripts/prune-unused-css.mjs <файл.css> <страница.vue> [ещё .vue]` удаляет правила для классов, которых больше нет в разметке. Оставшееся удаляется руками, `!important` не добавляется.
